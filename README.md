# 🐍 Exercices et Travaux Pratiques Python

Ce dépôt regroupe l'ensemble de mes travaux pratiques et exercices d'algorithmique réalisés en Python. 

Il me sert de référentiel technique pour consolider mes compétences en développement logiciel et suivre mon évolution vers des concepts plus avancés dans le cadre de ma Licence Informatique.

## 📂 Structure du projet

* **TP1 - Les fondamentaux**
  * Manipulation avancée des structures de données (Listes, Dictionnaires).
  * Traitement de données : Lecture, extraction et écriture de fichiers `.txt` et `.csv`.
  * Création de menus interactifs en console (utilisation de `match...case`).

* **TP2 - Analyse de données (NumPy)**
  * Création et manipulation de tableaux via `np.array`.
  * Calculs statistiques rapides (`.mean()`, `.min()`, `.max()`).
  * Extraction et comptage de données à l'aide de masques booléens.

## 🛠️ Technologies et Outils

* **Langage :** Python 3.x
* **Bibliothèques externes :** `numpy`
* **Modules natifs :** `csv`
